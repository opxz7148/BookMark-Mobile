# BookService
- Create new book from ISBN (query from some API)
- Create new book from user input
- Get book by ISBN (Search from DB)
- Get book by ID (Search from DB)
- Get batch of books by IDs (Search from DB)
- Get batch of books by ISBNs (Search from DB)

# CollectionService
- Add book to collection from ISBN
- Add book to collection from user input
- Remove book from collection
- Update book in collection (e.g. update reading status, rating, etc.)
- Get list of books in collection
